Installing

Windows

Run the installer and choose whether to install just for you or for everyone on the computer, and where it goes. Uninstall any time from Windows Settings.

Windows may show a warning. The app isn't code-signed yet, so SmartScreen may say it doesn't recognise it. Choose More info, then Run anyway.

To make sure you have the real file, compare its fingerprint with the SHA-256 shown above. In PowerShell, run Get-FileHash $HOME\Downloads\ecdh.chat-setup.exe

Linux

On Ubuntu, Debian and Mint, pick the .deb. It uses your system's web engine, so your regular security updates keep that part up to date. Open it with your software installer, or run sudo apt install ./ecdh.chat_amd64.deb. When there's an update, the app asks for your password to install it.

The AppImage brings everything it needs, runs on almost any distribution and updates itself. Make it executable, then start it: chmod +x ecdh.chat-x86_64.AppImage and ./ecdh.chat-x86_64.AppImage. Ubuntu 22.04 and newer need FUSE 2 for AppImages: sudo apt install libfuse2t64, or libfuse2 on 22.04.

Calls aren't in the Linux app yet. Chats, files and voice messages work as everywhere else; for calls, open ecdh.chat in a browser. Linux also can't hide a window from screenshots, so that setting is Windows-only.

To make sure you have the real file, compare its fingerprint with the SHA-256 shown above, for example with sha256sum ecdh.chat_amd64.deb

What the app adds

Code that ships with the app

The website gets its code from our server every time. The app brings its own, so what runs on your computer only changes when you update.

Privacy blur and screenshot blocking

Blur the chat whenever you switch to something else. On Windows it can also hide the window from screenshots, recordings and screen sharing.

Stays with you

Closing the window keeps your chat open in the tray, with quiet alerts that never show what was said. It can start when you log in, too.

Tiny and light

Under 2 MB on Windows and about 4 MB as a .deb, because it uses the web engine already on your system instead of bundling a whole browser.

Other devices

Apps for more platforms are on the way. Until then, ecdh.chat works in any up-to-date browser, on any device.
