About

How a chat works, start to finish.

  1. [01]

    A one-time invite link

    It contains a random room name and a 128-bit secret. The secret sits after the #, the part of a link that browsers never send to a server.

  2. [02]

    The server introduces you

    When the other person opens the link, the server passes the connection setup between your two devices. It never receives the secret.

  3. [03]

    A direct connection

    A peer-to-peer WebRTC connection is made. On a phone, you can let it fall back to our relay, which only ever sees encrypted data. The app asks you first.

  4. [04]

    A fresh key exchange

    Both devices make new keys and mix in the secret from the link, so only someone holding that exact link can join the conversation.

  5. [05]

    You compare the code

    Read it to each other over a call or in person. If the codes match, nobody is in the middle, not even someone who got hold of the link.

  6. [··]

    You chat

    Messages, files, voice notes, calls and screen sharing travel directly between the two of you.

  7. [06]

    Either of you ends it

    Ending the chat wipes it from both screens. The link can’t be used again.

  8. [07]

    When privacy matters

    Nothing was stored. Start a new chat any time.
