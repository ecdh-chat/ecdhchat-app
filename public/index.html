Privacy

How it works

  • A direct connection. Your browser connects straight to the other person’s. The server only introduces you and never sees your messages, files or calls.
  • A key in the link. Part of the invite link never reaches the server. Both browsers use it to lock the connection, so the server can’t read or change anything.
  • Encrypted end to end. Messages and files are encrypted with keys made fresh for this chat (ECDH P-256 and AES-256-GCM). Calls use WebRTC’s built-in encryption, and the code check covers them too. Nothing is stored, and closing the tab ends the chat.
  • Check the code. If someone else got hold of the link, comparing the 6-digit code over a call or in person shows whether anyone is in the middle.
  • One-time links. A link works for one person and expires if nobody uses it.
